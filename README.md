# ⚡ Objectified — High-Performance 3D Energy Drink Showcase

A high-end, ultra-interactive D2C landing page built for modern beverage and functional drink brands. Designed to deliver an immersive Apple/Awwwards-grade visual experience with buttery-smooth 60+ FPS performance on mobile and desktop devices.

![Objectified Preview](https://your-deployment-url.vercel.app/og-image.png) *(вставь сюда ссылку на скриншот/превью)*

---

## ✨ Key Features

* **Interactive 3D Can Showcase:** Dynamic 3D rotation, tilt, and parallax physics on mouse movement & scroll triggers.
* **Ambient Lighting System:** Background radial glow automatically transitions to match the active flavor palette (Classic, Mojito, Grape).
* **Mobile-First FPS Optimization:** Uses CSS GPU acceleration (`transform-gpu`, `contain: paint`) and `whileInView` triggers instead of heavy client-side scroll listeners for rock-solid 60+ FPS on mobile GPUs.
* **Cyberpunk & Glassmorphism Aesthetics:** Neon stroke gradients, custom glow effects, and optimized glass backdrop cards.
* **Next.js Image & Asset Optimization:** Native `next/image` lazy loading and WebP formats to guarantee instant paint times and zero layout shifts (CLS).

## 🚀 Getting Started

First, clone the repository and install dependencies:

\`\`\`bash
git clone https://github.com/objectxf/objectified-energy-drink.git
cd objectified-energy-drink
npm install
\`\`\`

Run the development server:

\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Build for production:

\`\`\`bash
npm run build
\`\`\`
